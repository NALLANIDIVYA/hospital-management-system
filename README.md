# Hospital Management System

## About the Project

The Hospital Management System is a Python and MySQL based application designed to manage hospital operations.

## Features

- Department management
- Patient management
- Doctor management
- Appointment booking
- Appointment cancellation and rescheduling
- Billing management
- Patient history
- Reports
- Login system
- Input validation
- MySQL database connectivity

## Technologies Used

- Python
- MySQL
- MySQL Connector/Python

## Project Structure

- `main.py` - Main program
- `login_module.py` - Login functionality
- `department_module.py` - Department management
- `patient_module.py` - Patient management
- `doctor_module.py` - Doctor management
- `appointment_module.py` - Appointment management
- `billing_module.py` - Billing management
- `reports_module.py` - Reports
- `db_setup.py` - Database and table creation
- `config.py` - Database configuration
- `validators.py` - Input validation
- `requirements.txt` - Required Python packages

## How to Run

1. Install Python.
2. Install MySQL.
3. Install the required packages:

pip install -r requirements.txt
